# 0.19.0 即时编辑模式

2026-10-10。

第三种模式保持大部分内容的原生渲染，点击当前段落或结构块，在原位修改 Markdown；约 180 ms 停顿后显示这一段的效果预览。点击「完成」、按 Esc 或激活下一块时收起语法。右上角第五个独立按钮切换即时编辑／阅读，快捷键 ⇧⌘L；原有第二个按钮仍切换双栏源码编辑／阅读。

这是块级原位编辑：当前块临时显示语法并有局部效果预览，不宣称逐字符隐藏 Markdown 标记或完整富文本排版。列表、引用、表格、代码围栏、独立公式按完整结构块编辑，保留标记、缩进和续行。行内公式随所在段落编辑。首次激活默认将光标放在块尾，可以继续点击源码中的位置；未实现从渲染字形到源码的精准首次点击映射，也未实现跨块拖选或表格单元格专用编辑器。

## 原文与生命周期

- Markdown 字符串仍是唯一保存与导出来源。激活、折叠和切模式不对整篇 AST 重序列化。
- 记录公式预处理的原始／替换 UTF-16 区间，将解析器 UTF-8 行列映射回原文。源编辑区间不能用滚动近似值或 block.format() 代替。
- 活动块只替换自己的原文区间，保留前后所有字节；没有可见节点的空白与引用定义保留。重叠的预处理节点合成一个可编辑区间。
- 活动编辑器有稳定 ID，后台解析与局部预览不会重建它；编辑器中的新段落可留在同一活动区间，折叠后重新分块。后续旧块的定位根据本次长度变化校正，刷新期间禁止旧位置命中。
- 每标签页使用统一文档撤销历史，三模式共用，记录差量及前后选区。原生控件不向同一个管理器注册私有 NSUndoTyping，避免已移除控件的撤销动作污染文档事务。接受外部新版本时清除旧历史。
- 输入法候选阶段不提交或保存半成品。保存、退出、关闭当前标签和模式切换前先收束当前输入；活跃即时编辑会话遇到外部改动按未完成编辑保护，保留草稿并提示冲突。
- 新模式继续使用现有原生 FormulaCache／Mermaid 资源、编码、原子保存、会话和 PDF 快照。纯文本文件使用原来的阅读／源码模式。

## 验证

- 精确范围：中文、emoji、组合字符、混合 CRLF／LF、UTF-8 BOM、无末尾换行、多行公式、引用、嵌套列表、代码围栏、表格及引用定义。激活未改动时源码／磁盘完全不变；实际修改仅替换所选区间。
- 原生中文输入长停顿、正式提交、局部效果、光标、选中词替换及撤销重新选中。
- 当前块内添加新段落后点击旧快照后续块，写入位置正确；跨块及跨模式 undo／redo、EOF 追加和 BOM 保存通过。
- 外部重载清旧历史、活跃块外部冲突、候选 closeAll 保存草稿并恢复、刷新期旧点击保护通过。
- 实际 Formula.md 隔离副本（550 处公式）顶部／中部／底部连续编辑：最长 10 ms 心跳间隔 75.69 ms，超过 100 ms 为零，活动原生编辑器 ID 保持不变，温热公式新增渲染为零。该值是离屏主线程／布局调度测量，非显示 FPS 或系统输入法候选窗口视觉延迟。
- Features 全套通过：原有连续输入、目录／滚动条、公式／图片／会话、Mermaid 与完整 9 页 A4 PDF。
- HTML 结构、30 个唯一 ID、两段脚本、公式、目录几何、组合输入定时器、UTF-16 原文拼接／CRLF 与撤销历史检查通过。没有自动打开浏览器或截图。
