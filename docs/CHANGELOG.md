## 0.18.3（2026-10-09）

- 修复公式密集长文滚动时每个公式完成都触发整片 Markdown 块重算的问题；改为相关块局部更新并合并通知。
- 公式图片采用 2,048 条／64 MiB 上限 LRU；新增 16 MiB SVG 缓存。后台预渲染所选文档，可见需求优先；切文档或字号替换旧后台队列。
- 减少滚动热路径的缓存键生成及段落公式菜单扫描；保留失败源码回退、原文复制、字号与屏幕比例区分。
- 同步已有 HTML 预览，增加 550 处公式的长文示例和公式结果复用；添加原生离屏性能检查及调度专项回归。

- Features 全套（含完整 9 页 PDF）、HTML 结构／脚本、长文顶部／中部／底部窗口与双栏调整及调整后滚动通过。未显示测试窗口、自动打开浏览器或截图。
- 18 项解析检查、Release 构建及签名通过；正常退出前后备份会话，直接安装 /Applications/LightMD.app 0.18.3（38）并恢复运行，核对安装二进制与签名后的构建一致、标签／草稿／选择恢复一致。
