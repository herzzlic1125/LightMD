## 0.17.0（2026-09-27）

- 右上角现有胶囊左侧新增 PDF 导出按钮；同步文件菜单与 ⌥⌘E，导出时显示忙碌状态。
- 以当前编辑快照导出完整 A4 PDF，包含正文、跨页表格、公式、本地图片与 Mermaid；先完成临时文件再原子写入，错误资产保留源码／占位并提示。
- 增加 `mermaid` 代码围栏离线渲染：中文节点、分支箭头、常用时序图、明暗主题、宽度缩放和源码复制；语法错误显示原代码。
- 修复重复构建时旧许可证文件为只读、导致打包失败的问题；许可证以明确的可读写权限重新安装。
- 打包官方 Mermaid Tiny 11.17.2 与许可、记录校验和；使用系统离屏排版页和原生图表缓存，隔离外部资源访问。
- PDF 使用后台分页任务，避免主线程同步打印读取未完成的页数；生成过程不显示额外窗口。复用现有数学 SVG 与图片解码，普通正文仍可选择和搜索。
- 同步现有单文件 HTML 预览，内嵌同版本图表资源，支持真实图表编辑和浏览器打印存为 PDF。
- 完整离屏回归通过：9 页 A4、650 个长段落片段、65 行表格、末尾文字、图表标签和本地图片像素，以及源码保护、资源错误回退、图表缩放和独立资源打包。详情见 EXPORT-0.17.0.md。

## 0.16.0（2026-09-27）

- 增加离线 LaTeX 显示：支持四种分隔符、分式、上下标、矩阵、中文分段函数和多行对齐；异步缓存渲染，失败保留源码，段落右键可复制原始公式。
- 修正公式依赖的默认数字匹配规则，避免数字后的运算符、矩阵列或行分隔符被吞掉；新增结构级回归检查。
- 增加本地／相对路径图片显示，支持中文和空格文件名、常见位图及 SVG；按比例缩放，点击通过系统快速查看显示原图。
- 增加会话恢复：标签顺序、当前选择、阅读位置和未命名草稿；正常退出先保存已有文件，再原子写入会话。恢复时保护外部修改和丢失文件的草稿，冲突状态跨连续重启保留，损坏会话先备份。
- 保留 Markdown 原始内容与行定位；没有公式的文档跳过公式预处理，避免额外解析开销。
- 同步现有 HTML 预览、使用说明与维护规则；更新至 0.16.0（32）。
- 增加可重复的离屏功能检查与独立资源打包验证，详情见 FEATURES-0.16.0.md。

## 0.15.0（2026-09-27）

- 未选中的文件标签在悬停时文字变深并显示关闭按钮；预留关闭按钮位置，避免标签宽度跳动。

- 离屏验证通过实时源码宽度变化、长文双向定位，以及延时合并、后台标签、冲突、删除文件、UTF-16 BOM、关闭／退出保存、失败重试和未命名文件行为。

## 0.14.1（2026-09-27）

- 分隔线改用 AppKit 光标追踪和鼠标拖动，恢复左右调整光标；同时修正预览外层错误占用整个分栏宽度的布局层级。
- 预览改为按需创建内容块；模式与目录过渡通过动画中间值进行真实排版，避免整篇正文参与每次宽度变化。
- 长文滚动改为按源码范围定位内容块，未显示的章节先加载再校正位置；补齐文末对齐、重复远处定位和切换标签后的过期请求保护。
- 拖动期间固定源码的换行宽度，松手后重排并重新对齐；预览持续实时换行。取消拖动、切换模式或标签、移除编辑器时都会恢复源码宽度跟随。
- 同步 HTML 预览与使用说明；增加离屏回归验证和性能记录，并记录测试不得置顶的要求。
