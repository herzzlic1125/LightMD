# LightMD 更改记录

## 0.15.1（2026-09-27）

- 修复慢速滚动时标题接近视口顶部、另一栏突然跳动的问题；在内容块起止点及块间空白之间连续插值。
- 保留视口附近刚离开的定位数据，避免懒加载回收内容块时重复跳回该块顶部；正文宽度或内容高度改变后更新这些数据。
- 同步 HTML 预览；六级标题和双向慢滚离屏回归通过。

## 文档维护（2026-09-27）

- 将字体记录整理为应用自身的字体角色说明，统一文档名称与构建排除项。
- 清理当前文档和既有提交中的外部应用对比叙述，保留功能变更的提交顺序。

## 0.15.0（2026-09-27）

- 未选中的文件标签在悬停时文字变深并显示关闭按钮；预留关闭按钮位置，避免标签宽度跳动。
- 取消拖动时冻结源码宽度的处理，左右两栏现在都实时换行；启用 AppKit 非连续文本排版，以改善长文中的实时重排成本。
- 已有路径的文件停止输入约 1 秒后自动保存；每个标签独立计时，关闭标签和退出前会立即写入待保存编辑，⌘S 仍可立即保存。
- 自动保存沿用原文件编码和外部修改检查；冲突或写入失败时保留草稿，失败信息在对应标签内显示。未命名文件首次手动选择位置后启用自动保存。
- 避免自动保存成功后重复解析已更新的预览；同步 HTML 交互预览、说明及项目维护规则。
- 离屏验证通过实时源码宽度变化、长文双向定位，以及延时合并、后台标签、冲突、删除文件、UTF-16 BOM、关闭／退出保存、失败重试和未命名文件行为。
- 记录用户授权：以后更新时可直接正常退出运行中的 LightMD 并安装，无需重复确认。

## 0.14.1（2026-09-27）

- 分隔线改用 AppKit 光标追踪和鼠标拖动，恢复左右调整光标；同时修正预览外层错误占用整个分栏宽度的布局层级。
- 预览改为按需创建内容块；模式与目录过渡通过动画中间值进行真实排版，避免整篇正文参与每次宽度变化。
- 长文滚动改为按源码范围定位内容块，未显示的章节先加载再校正位置；补齐文末对齐、重复远处定位和切换标签后的过期请求保护。
- 拖动期间固定源码的换行宽度，松手后重排并重新对齐；预览持续实时换行。取消拖动、切换模式或标签、移除编辑器时都会恢复源码宽度跟随。
- 同步 HTML 预览与使用说明；增加离屏回归验证和性能记录，并记录测试不得置顶的要求。

## 0.14.0（2026-09-26）

- 双栏滚动从整篇百分比同步改为按 Markdown 源码行与预览块位置对齐；列表项和纯文本行也有对应锚点，两个锚点之间按实际位置插值。
- 编辑模式仍默认源码 40%、预览 60%；分隔线的可拖动区域扩大到 14 点，并按拖动位置立即调整两栏。
- 阅读／编辑模式切换及右侧目录开合时，预览宽度和正文换行与动画同步更新；减少动态效果设置下直接切换。
- 在文件标签下方新增当前文件完整路径；未命名标签不显示。
- 同步更新现有 HTML 预览与使用说明。
