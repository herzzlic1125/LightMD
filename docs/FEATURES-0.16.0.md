# LightMD 0.16.0 功能验证

日期：2026-09-27。版本：0.16.0（32）。

## 本轮范围

1. 离线 LaTeX 数学公式。
2. 本地／相对路径图片及点击快速查看。
3. 标签、当前选择、阅读位置与未命名草稿恢复。

生产实现：`MathMarkup.swift`、`MathRenderer.swift`、`MediaSupport.swift`、`SessionStore.swift`，接入 `LightMD.swift`、`EditorSupport.swift`。现有 HTML 预览同步更新。

## 验证结果

- **公式解析**：四种分隔符、跨行公式、CRLF、源码行范围；代码围栏、缩进代码、行内代码、价格、转义美元、链接与图片路径排除，通过。
- **公式结构**：矩阵、中文分段函数、数字紧邻换行的 aligned 均为两行四格；`1+2` 保留两个数字与一个运算符；小数及千位分组通过。显式修正 MathJaxSwift 3.5.0 的默认数字正则，未修改公式空白或原文。
- **公式绘制**：中文文本、上下标、分式、矩阵、cases、aligned 均生成非空像素；不同字号尺寸变化正确，未知命令回退源码。实际离屏 ReaderView 完成公式排版，随后自动保存仍保持原 Markdown 字节内容。
- **图片**：中文、空格、URL 编码相对路径解析正确；PNG 和 SVG 保持 2:1 宽高比；网络 URL 不作为本地文件加载。实际视图显示接入通过。快速查看使用系统 API 绑定；未打开可见面板做人工视觉检查。
- **会话数据**：标签顺序、选择、阅读书签、非空及空的未命名标签恢复通过；普通已保存文件不重复存全文。正常退出保存已有文件并保留未命名草稿；会话写入失败时阻止退出并保留草稿。
- **冲突与损坏**：外部修改、缺失文件及连续重启后的冲突保护通过；不可读会话在重新写入前备份。
- **阅读位置**：838 行普通长文在双栏保存、阅读模式恢复后，目标块偏差约 0.15 点；100 节包含公式和 SVG 的长文约 0.16 点；切换标签后定位及重复打开文件不增加标签通过。
- **离线安装资源**：把测试程序签名为标准 app，公式资源位于 `Contents/Resources`；暂时隐藏 `.build` 中的资源后，完整功能检查仍通过，随后恢复构建资源。
- **HTML**：25 个唯一 ID；内联 JavaScript 语法及纯函数检查通过。五个代表公式、矩阵／分段行数、图片、代码／价格排除与十二个长文段落通过。未打开浏览器、运行浏览器自动化或截图。

## 可重复检查

完整构建使用 `./build.sh`，运行 18 个 CJK 解析检查、Release 编译、资源打包、签名与安装。

之后执行 `python3 Checks/Features/run.py` 可重复公式、图片、会话及资源独立性检查。测试使用隔离目录、`NSApplication` 禁止激活策略和不显示的窗口，不读写用户真实会话。发布构建使用 Release；当前命令行工具链不具备 SwiftDraw Debug 预览宏。

## 当前边界

- 不加载网络图片；动图显示首帧。
- 数学宏以内置 MathJax 包支持为准，不支持时保留原公式。
- 显式“复制公式源码”菜单保留原始分隔符；跨正文选区复制不保证把公式图片转换回 LaTeX。
- HTML 仅演示代表公式和浏览器会话，使用浏览器本地存储，不会写回磁盘 Markdown。
- 无法读取且没有草稿的旧文件不恢复；有草稿的保留草稿并提示冲突。

## 发布确认

`./build.sh` 完整通过，18 个解析检查通过；已正常退出旧版并更新 `/Applications/LightMD.app`。安装版为 0.16.0（32），严格签名验证通过，系统 `.md` 默认打开路径仍为该安装版。没有启动或置顶安装后的应用。
