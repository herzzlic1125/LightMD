# LightMD 0.17.0 PDF 与 Mermaid 验证

日期：2026-09-27。版本：0.17.0（33）。

## 实现

- `WindowChrome.swift`：在右上角原胶囊左侧添加导出图标和忙碌状态。
- `PDFExport.swift`：冻结当前标签源码、路径、字号和标题，重新使用同一 Markdown 解析器生成完整文档；等待公式、图片与图表后打印，最后原子写入目标。源文件覆盖与符号链接别名覆盖会被拒绝。
- `MermaidSupport.swift`：固定官方 Tiny 11.17.2，严格模式、离线渲染、串行队列、缓存、浅深主题、错误源码回退和原生尺寸自适应。
- `WebRenderSupport.swift`：不显示的系统 WebKit 页面；隐藏窗口从窗口菜单排除；使用异步后台打印完成 A4 分页，关闭所有打印面板。
- `MathRenderer.swift`：在既有串行数学引擎中增加 SVG 导出入口，继续使用已修正的数字匹配规则。
- `LightMD-preview.html`：沿用原预览，内嵌同版 Mermaid runtime；提供真实编辑、图表错误回退、导出按钮及打印样式。

## 离屏验证

命令：`python3 Checks/Features/run.py`。

- 原 0.16.0 的公式、图片、会话、冲突与源码保存检查全部通过。
- Mermaid 流程图中文节点、箭头与标签、时序图、明暗主题、缓存命中、错误后的下一次绘图恢复通过。
- 原生 Mermaid 视图从 300 点缩到 200 点时，图形高度按比例缩小，通过。
- 完整测试文档生成 **9 页 A4**，每页约 595 × 842 点。650 个长段落片段、65 行表格与末尾标记全部可从 PDF 提取，未发生视口截断。
- PDF 中提取到流程图开始和结束节点；离屏检查得到 **20,094 个示例图片蓝色像素**，确认本地图片实际进入页面。
- 导出包含点击时尚未发布到预览的编辑快照；异步期间之后的编辑没有混入同一份 PDF。
- 源文件字节保持原样，禁止覆盖源文件；无效公式、缺失图片、错误流程图分别保留原文／占位，返回三项提示，末尾内容仍存在。
- 在临时隐藏构建目录公式资源的情况下，签名测试包仍完成全部检查；Mermaid 从包内 Resources 加载。
- 测试没有显示窗口，测试进程没有成为前台应用。PDF 只由 PDFKit 做数据与像素检查，没有打开 PDF 查看器或网页。

- HTML 预览通过 `python3 Checks/Features/check-preview.py`：标签结构、唯一 ID、两个内联脚本语法、公式／图片／Mermaid 代码围栏与源码范围纯函数检查。未启动浏览器。

- 重复构建修复：许可证改用 `install -m 644` 复制，避免继承依赖 checkout 的只读权限导致下一次打包失败。

## 限定范围

- PDF 固定 A4 与约 12.7 mm 边距；尚无纸型、页眉页脚设置面板。
- PDF 正文保持文本；数学公式以矢量图形导出，不承诺公式可复制回 LaTeX。
- 使用 Mermaid Tiny 的内置图表，不含架构图、思维导图、ELK 或图内 KaTeX。网络图片仍不加载。
- 原生和 PDF 正文使用相同解析结果及字体角色，具体断行由各自排版器决定。
- 保留 macOS 13 最低系统配置；当前系统的 Release 构建和回归通过，未测试 macOS 13 真机。
