# 图标说明

公开版图标为本项目通过图像生成工具新生成的纸张字标设计，没有使用第三方图片作为输入。

设计元素：暖白纸张、深墨绿色衬线字母 M、向下箭头与陶土色书签。原始文件为 `Assets/LightMDIcon.png`；构建脚本生成标准尺寸的 macOS 图标资源。

图标在项目方有权授权的范围内与项目一并按 MIT 许可证提供。生成式图像不意味着自动取得排他性著作权；本项目不对图标设计主张额外的独占使用限制。
