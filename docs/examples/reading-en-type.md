# Words need space

Reading feels easier when the page has a clear rhythm. LightMD gives **important ideas** weight while leaving enough room around each paragraph.

## A measured line

A comfortable line width helps the eye find the next line. Headings mark the structure without crowding the text below them.

The next paragraph starts after a small pause. English letters and 0123456789 use a system serif face; `inline code` keeps its own even rhythm.

**Emphasis can be firm.** *A quieter note can be gentle.* Small details make long reading sessions more comfortable.
